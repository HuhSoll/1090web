# 研究用語集（Phase 9I）

1090web の研究機能で使う言葉の定義です。フェーズの間で同じ言葉が違う意味にならないよう、Phase 9I で調べてまとめました。条件や分母が違う数値は、直接比べないでください。

| 用語 | 定義 | 使う場所 | 注意 |
| --- | --- | --- | --- |
| 便数（観測便数） | ADS-B で観測された航跡のうち、出発・到着の空港が判定でき（T1〜T4）、出発≠到着の記録の数。基準時刻（航跡の開始、なければ終了）が期間に入るものを数える | すべて | 時刻表の便数・運航便数・欠航数ではない。期間の長さで変わる：1 日の便数と 1 か月の便数は比べない |
| 1 日あたりの便数 | 期間の便数 ÷ 期間の日数（収集停止の日を除く場合は除いた日数） | 9B・9G・9H | 月次の「便数」とは分母が違う |
| 接続（弧） | 有向の空港の組（A → B）で、期間に閾値以上の便があるもの | 9C・9E | 無向の「路線」（A–B）とは数が違う。有向の接続数は無向の路線数のおよそ 2 倍 |
| 路線 | 無向の空港の組（A–B） | 探索・9G の路線の変化 | 「後だけ観測」は新規就航、「観測されなくなった」は廃止を意味しない |
| 到達可能 | ネットワーク上で経路（ホップの列）がある | 9C〜9E | 座席・乗り継ぎ・時刻を考えない構造上の到達。9F の「行ける」とは別 |
| 行ける（9F） | 道路と、運航回数の条件（毎日・週 1 便以上・回数を問わない）を満たす定期便で目的地に着ける | 9F | 「毎日の便で行けなくなる」は「島から出られなくなる」ではない |
| ネットワーク効率 | 順序付きの空港の組の 1/距離（ホップ数）の平均。到達できない組は 0。分母は基準の空港の集合で固定 | 9C〜9E | 停止した空港は孤立ノードとして残す |
| Systemic | 空港 v を止めたときの、全空港の組の効率の低下（v 自身の組を含む） | 9E | Spillover とは分母が違う |
| Spillover（波及） | v 以外の空港の組の効率の低下。前は v を通る経路を含み、後は通れない | 9C・9E | 末端の空港は 0。厳密には 0 の値に ±1e-17 の誤差が出るので、順位は丸めた値で比べる |
| 順位 | 1e-12 で丸めた値の大きい順。同じ値は同順位（1224 方式） | 9E | 候補の中の順位は全空港の中の順位ではない（157 空港 ≠ 3,883 空港） |
| 影響人口（9F） | 停止の前後で条件が悪くなる 250 m メッシュの居住人口（2020年） | 9F | 旅行需要や患者搬送の推計ではない。「対象人口（島）」と「影響を受ける人口（複数の島）」を区別（新石垣：石垣島 47,637、影響 49,822） |
| 停止（シミュレーション） | 空港・路線・航空会社を、仮想的にネットワークから取り除くこと | 9C・9D | 実際の閉鎖・欠航ではない |
| 閉鎖（イベント） | 当局・報道が述べた空域・空港の閉鎖 | 9H | 勧告・運航者限定の制限は閉鎖ではない。閉鎖でも特別便などの例外がありうる。自動で停止に変えない |
| 勧告 | 運航者への推奨（EASA CZIB、FAA の KICZ NOTAM など） | 9G・9H | 空域閉鎖ではない |
| 欠測（観測） | 受信網で捉えられなかった便。実際にあった便が記録にない | 9E・9I | 「観測ゼロ」とは別 |
| 収集停止 | 世界全体で、1 時間の観測が通常の 5% 未満になった時間帯（2026年5月5〜7日など） | 9A・9B | 航空交通の停止ではない。部分的な欠け（通常の 1〜4 割、5月4日など）は含まれない |
| 観測ゼロ | ある系列の観測便が 0 | すべて | 収集停止・受信網の範囲外・実際の運休のどれかで、区別が必要 |
| 計算不能 | 必要な入力（時刻・人口・経路）がなく、値を出せない | 9F・9G | 0 として扱わない |
| データ不足 | 判定に必要なデータが足りず、どちらとも言えない（9F の代替交通の 4 分類の 1 つ） | 9F | 「経路なし」とは別 |
| 重要度 | 止めたときの効率の低下（Systemic・Spillover）で測る、ネットワーク構造上の重要さ | 9E | 便数の多さとは別（ORD は便数 1 位だが Spillover 25〜28 位） |
| 信頼性 | 観測の確かさ（受信の範囲、T4 の割合、異常の判定） | 研究モードの信頼性タブ | 統計的な信頼区間ではない |
| 近似 | 起点の空港をサンプルして距離を計算すること | 9E | 近似の誤差は、条件・欠測によるばらつきとは別 |
| 事前トレンド | 前の期間の log(便数+1) の直線の傾き。t は Newey-West の標準誤差（9I から） | 9G・9H | |t| < 2 でも「傾きがない」証明ではない |
| プラセボ | イベントのない過去の日で同じ比較をしたもの | 9G・9H | 件数（4 日など）を必ず併記する。有意性の検定ではない |
| 比較対象群に対する変化 | 対象地域と比較対象群の log 平均の変化の差（いわゆる DiD） | 9G・9H | 記述的な値。効果の推定値ではない（9I から） |
| 検証済み（研究成果） | 記したデータ・条件・範囲について独立に確かめた | 研究成果 | 現実の世界で絶対に正しいという意味ではない |
| 勧告の対象国の便 | 対象国の空港を発着する便 | 9G・9H | 対象 FIR を通過した便ではない（1090web は通過を推定しない） |
