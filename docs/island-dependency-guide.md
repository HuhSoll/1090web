# 離島の依存性：使い方（Phase 9F）

研究モードの「離島の依存性」タブで、沖縄県の離島の空港が使えなくなったとき、住民の移動の手段がどう変わるかを調べられます。計算方法は [island-dependency-methodology.md](island-dependency-methodology.md)、データは [island-data-sources.md](island-data-sources.md) にあります。

## 対象

| 島 | 空港 | 主な船 |
| --- | --- | --- |
| 宮古島・伊良部島・下地島・池間島・来間島（橋でつながる） | 宮古（MMY）、下地島（SHI） | 平良〜多良間 |
| 石垣島 | 新石垣（ISG） | 石垣〜西表、石垣〜与那国 |
| 西表島 | なし | 石垣〜大原・上原 |
| 与那国島 | 与那国（OGN） | 石垣〜与那国（週2） |
| 多良間島 | 多良間（TRA） | 平良〜多良間（週6） |
| 南大東島・北大東島 | 南大東（MMD）、北大東（KTD） | 那覇〜南北大東（年60） |

左の分析条件（月・地域など）はこのタブでは使いません。

## 基本の操作

1. 研究モードの「離島の依存性」を開きます。
2. **島**を選びます。空港のある島ではその空港が、空港のない島（西表島）では住民が使う空港（新石垣）が自動で選ばれます。
3. **停止する空港**を確認します。複数選べます。
4. **目的地**（那覇＝沖縄本島の拠点、福岡・鹿児島・東京＝本土）と、**数える便**（毎日運航の便だけ／週1便以上／運航回数を問わない）を選びます。
5. 「**この空港が停止したら？**」を押します。

## 結果の見方

最初に表示するもの：

- **対象人口**：選んだ島の 2020年の人口
- **毎日の便で行けなくなる**：毎日運航の便だけでは目的地に行けなくなる住民
- **まったく行けなくなる**：定期便の経路が一つもなくなる住民
- **アクセスが悪化**：選んだ条件で、行けなくなる・時間が増える・便の少ない経路になる住民
- **追加の移動時間**：時間が増える住民の平均（待ち時間を含まない）
- **比較できない**：経路はあるが、所要時間が確認できない住民（那覇〜本土の便など）
- **停止後に住民に残る手段**：別の空港の航空便、船、なし、の人口
- **データの品質**：人口・運航の基準時点、モデルの意味、ADS-B で見えない路線

「行けなくなる」住民は時間の平均には入りません。「比較できない」は「悪化」に入りません。

### 地図

- 四角は住民のいる 250 m メッシュです。「変化」「停止前」「停止後」を切り替えられます。
- 「変化」：赤＝行けなくなる、黄＝時間が増える、橙＝便が少ない経路になる、灰＝比較できない。
- 「停止前」「停止後」：時間を 1.5・3・6・12 時間の粗い区分で塗ります。待ち時間を含まないため、指定した時刻に移動できる時間ではありません。
- ▲は空港（停止した空港は赤）、■は港、点線は島の間の橋です。

### パイロットの全島

選んだ空港の停止で、ほかの島の住民がどう変わるかを表で示します（新石垣の停止で西表島の住民も影響を受けるなど）。CSV（メッシュ別）と JSON（集計と条件）で保存できます。

## 詳しい条件

「詳しい条件」を開くと、次を変えられます。

- 航空・船舶を使うか
- 島の間の橋を使うか
- 季節便（7〜8月）を含めるか
- 時間の上限（その時間以内に行ける住民の変化を数える）
- あわせて止める船の航路（代替交通の停止。空港の停止とは別に、停止後の側だけに適用）

## 条件の比較

「条件の比較（感度分析）」で、同じ停止を、便の頻度・船なし・橋なし・季節便・目的地を変えて計算した結果を並べます。

## 世界的な重要度との比較

「世界的な重要度（Phase 9E）と住民の依存性」で、Phase 9E の Systemic / Spillover の順位と、住民の依存性を並べます。

- 「観測」は ADS-B のネットワークでの順位です。与那国・多良間・南大東・北大東は観測便がないため「観測なし」です。
- 「離島路線を補完」は、県の資料の路線を加えたネットワークでの位置です（9E の分布に対する位置で、正確な順位ではありません）。
- 図の横軸は Systemic の位置（左ほど世界的に重要）、縦軸は毎日の便で行けなくなる住民（対数）です。2 つを足した点数は作りません。

## シミュレーションから

シミュレーションで宮古・下地島・新石垣などの空港を止めると、「保存と出力」の欄に「**地域住民への影響を調べる**」が表示されます。押すと、止めた離島の空港を引き継いでこのタブを開き、計算します。シミュレーションの期間や絞り込みは使いません（このモデルは観測便ではなく定期便の運航回数を使うため）。与那国・多良間・南北大東の空港は ADS-B の地図にないため、シミュレーションでは選べません。このタブで直接選んでください。

## 注意

- 結果は、確認できた交通網の有無と所要時間による分析（モデル A）です。時刻表を使う分析（モデル B）はまだありません。
- 便の座席数、欠航、天候、出発までの待ち時間は考えていません。
- 人口は 2020年、運航は 2025年、観測便は 2026年のデータです。
- 旅行の需要や患者搬送の需要の推計ではありません。
