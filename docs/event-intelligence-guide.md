# イベント調査：使い方（Phase 9H）

研究モードの「イベント調査」タブでは、安全勧告、空域の制限・閉鎖、空港の閉鎖、安全保障上の出来事、再開を、観測された便と同じ時間軸で見られます。計算方法は [event-intelligence-methodology.md](event-intelligence-methodology.md)、出典は [event-intelligence-sources.md](event-intelligence-sources.md) にあります。

## 絞り込み

- **開始・終了**：期間です。初期値は選んだイベントの 8 日前から 21 日後までです。
- **国・FIR・空港**：`QA OTDF OTHH` のように空白で区切って入力します。どれかに関わるイベントが残ります。
- **検索**：題名・説明・文書番号の文字列で絞ります。
- **種類・検証状態**：チェックを外すと隠れます。

## タイムライン

- A 安全保障、B 制限・閉鎖、C 勧告、D 観測便数、E 仮想の各レイヤーを、チェックで表示・非表示にできます。
- 実線の棒は時刻がわかる出来事、斜線の棒は日付しかわからない出来事（1 日全体）、破線の棒は報道だけの出来事です。終了が不明なものは右端に「…」が付きます。
- 上部の帯は、2 つ以上のイベントが同時に有効な期間です。
- D は、比較を実行した後に対象地域の日別便数を表示します。前後の期間は背景の色で示します。
- E はシミュレーションのシナリオのイベントで、実際の出来事ではありません。
- 棒を押すと、そのイベントを選びます。

## イベントの一覧と詳細

一覧には、最初にわかる時刻、種類、題名、対象、検証状態が並びます。CSV で保存できます。

詳細には次の項目があります。

- **種類・発出元・対象**：閉鎖の範囲、運航者（たとえば FAA の措置は米国の運航者だけ）、高度も表示します。
- **時刻**：発生、発表、有効の開始、有効の終了、資料で初めて確認。出典ごとの値を精度と根拠とともに示します。日付しかわからない時刻に時刻を補うことはしません。
- **出典で確認できること・確認できないこと**
- **出典**：種類（当局・保存版・国営通信・報道）、取得日、SHA-256 の先頭。
- **同じ時期のイベント**：前後 3 日のイベントです。出典が関係を述べているものだけ「出典で確認された関係」と表示し、それ以外は「時間的に近いだけ」です。以前から有効なものには「それ以前から有効」と付きます。

EASA CZIB を選んだときは、Phase 9G と同じく版の選択とイベントのカードも表示します。

## 前後のネットワークを比較

1. イベントを選び、期間（7・14・28・30 日）と空港の推定の範囲（T1〜T4、T1〜T3 のみ）を選びます。
2. 「前後のネットワークを比較」を押します。

国の指定がないイベント（FIR だけのもの）は比較できません。

結果の内容は Phase 9G と同じです（[historical-events-guide.md](historical-events-guide.md)）。

- 観測された変化
- 事前トレンド
- プラセボ
- DiD の条件
- 地図
- 空港・路線・航空会社
- 仮想停止との比較

これに次の表示が加わりました。

- **比較期間に含まれる実際のイベント**：前、イベント日、後の期間に、対象地域で有効だった・起きたイベントです。前後の変化は、これらのどれによるものかもしれず、ここにない出来事によるものかもしれません。日付だけのイベントが時差のために期間の端にかかる場合は、その旨が付きます。
- **検証の警告**：選んだイベントが「検証済み」でなければ表示します。

一度計算した結果は、タブを切り替えても残り、同じ条件ではすぐに表示されます。研究結果は JSON で保存できます。

## シミュレーションのタイムラインから

シミュレーションのタイムラインで「実際のイベント」にチェックを入れると、A・B・C の 3 行が表示されます。棒を押すと、研究モードのイベント調査でそのイベントを開きます。実際のイベントはシナリオに入らず、何も停止させません。

## 読むときの注意

- 時間的に近いことは、原因であることを意味しません。初期のケースでは、攻撃、EASA の勧告、各国の閉鎖が同じ日に重なっています。
- 報道だけのイベント（未検証）は、当時何が報じられたかを示すもので、確定した事実ではありません。
- 勧告や運航者限定の制限は閉鎖ではありません。閉鎖として報じられたものにも、特別便などの例外があり得ます。
- 湾岸の空港の便は、多くが便名から推定した発着地です（T4）。「T1〜T3 のみ」と比べてください。
