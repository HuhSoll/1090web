## 1. 実装した Research Mode の機能

画面右上に「探索／研究」の切り替えを追加しました（Explore Mode への唯一の見た目の変更です）。Research Mode は独立した画面で、既存のパネル・ボタン・色の定義（CSS 変数）をそのまま使った暫定的な配置です。研究画面を開いている間は地図の描画ループを止め、戻ると再開します。Explore Mode の状態（月、絞り込み、選択中の空港、地図／地球儀）は保持されます。

| 領域 | 内容 | 状態 |
| --- | --- | --- |
| A. 分析条件 | 対象月、国・地域、接続の種類（すべて／国内／国際）、空港、航空会社コード、機材の分類、月間便数の下限（1・4・10・30 と任意の値）、観測月数の下限、根拠区分（A〜D、既定 D）、有向／無向、経路計算の方法・起点数・シード | 実装 |
| B. ネットワーク概要 | 空港数、路線数、観測便数、暦日あたりの便数、平均次数、密度、連結成分、最大連結成分、強連結成分（有向）、平均クラスタ係数、推移性、根拠区分の構成、閾値で除かれた路線・便、計算方法・計算時間 | 実装 |
| C. 空港・路線ランキング | 指標を切り替えられる空港ランキング（並べ替え、検索、同順位の扱い）、選択した空港の詳細と主な路線、「地図で表示」、路線ランキング（便数、前月比、T1〜T4 の内訳、観測月数） | 実装 |
| D. 国・地域 | 国単位・大陸単位の切り替え、国際便数、国内（域内）便数、接続先の数、主な接続先、国・地域の組のランキング、行をクリックしてその地域を分析 | 実装 |
| E. 信頼性と外部照合 | データセットの版・期間・ルール・コミット・入力のハッシュ、その月の根拠構成と異常日・収集停止、大陸の根拠構成、同じ条件の外部照合（米国 BTS・ブラジル ANAC・日本 MLIT）と条件の違い、空港の公式発着回数との比、地域ごとの注意 | 実装 |
| F. 比較 | 月・閾値・根拠区分・地域のうち1つを変えて比較。変えた条件と同じ条件の表示、ネットワーク指標の差、上位20の一致率・Jaccard・Spearman・Kendall τb、順位の変化、上位20から出入りした空港、収集停止の警告 | 実装 |
| G. 出力 | 空港・路線・国・地域・概要・比較の CSV、条件と出典の JSON、JSON からの条件の復元（版の照合と警告）、条件付きの共有リンク | 実装 |

**地図との連動**：ランキングで空港を選び「地図で表示」を押すと、Explore Mode に切り替わり、同じ月・国・航空会社・閾値・根拠（T1〜T3／T1〜T4）でその空港の路線が強調されます。Explore Mode で表現できない条件（根拠区分 T1／T1〜T2、地域、国内・国際、有向、継続性、分類の一部、空港の絞り込み）は、地図の下に一覧で表示します。

**共有 URL**：`?mode=research&rm=2026-08&rt=C&rmin=10&rcmp=minFlights:30` のように、条件と比較の設定を URL に保存し、開くと復元します。

## 2. 追加した計算指標と定義

次数（入・出）、次数中心性、重み付き次数、媒介中心性（ホップ数、正規化あり）、調和近接中心性、PageRank（便数で重み付け）、連結成分（弱・強）、密度、クラスタ係数（局所・平均）、推移性。定義・正規化・近似の方法は [research-methodology.md](research-methodology.md) §4。

- 経路の長さはホップ数です。便数を距離として使うことはありません。
- 媒介中心性・近接中心性は既定で正確計算（Brandes）です。非常に大きなネットワークでは起点のサンプリング（シード付き）に切り替わり、その場合は「近似」と表示し、アルゴリズム・起点数・シード・正規化を記録します。2026年のデータでは、全世界の全路線でも正確計算の範囲に収まります。

## 3. データの利用方法

| ファイル | サイズ | 内容 |
| --- | --- | --- |
| Explore の月別ファイル（既存） | 約 4.4〜5.4 MB／月 | そのまま再利用（Explore と同じ読み込み処理・キャッシュ） |
| `research-web/tiers/YYYY-MM.json` | 約 0.9〜1.2 MB／月 | T2・T3 の内訳だけ（月約 4 万件） |
| `research-web/persistence.json` | 0.6 MB | 路線ごとの観測月数（根拠区分の組ごと） |
| `research-web/quality.json` | 0.5 MB | 品質・異常日・外部照合（必要な条件の行だけ、列形式） |
| `research-web/manifest.json` | 4 KB | 各ファイルと入力の SHA-256 |

合計約 12 MB（GitHub Pages では gzip で配信）。研究用の Parquet、元データ、外部統計の原本は公開していません。月別ファイルは必要な月（対象月と前月、比較する月）だけ読み込み、結合した月は最大4か月分をメモリに保持します。

生成手順：`python pipeline/research_web.py --dataset observed-2026-v2`（[pipeline.md](pipeline.md)）。品質情報や外部照合が欠けている場合は「外部照合のデータがありません」「未検証」と表示し、値は作りません。

## 4. 各分析の注意点

- **根拠区分**：T1〜T4 は空港の決め方の区分で、正しさの確率ではありません。T1 だけに絞ると、空港・便が大きく減ります（下の例）。
- **閾値**：低頻度の路線を除くと、季節路線や本当に運航の少ない路線も消えます。接続先の数は閾値の影響を大きく受けます。
- **継続性**：データに含まれる月だけで数えます。路線がない月は「観測されなかった」であり、運休ではありません。
- **国・地域**：国どうしの便数は旅客の流れではありません。受信網の密度が地域によって違います。
- **2026年5月**：5〜7日に収集停止があります。比較では警告し、実験的な補正は参考値として区別して表示します。
- **外部照合**：条件付きの照合で、精度ではありません。照合条件と分析条件の違いは常に表示します。
- **指標の意味**：観測ネットワークの構造指標で、旅客数・経済的な重要度ではありません。

## 5. 実行性能の検証結果（実測、開発用 PC、Chrome 系ブラウザ）

| 条件 | 空港 | 路線 | 指標の計算時間（Worker 内） |
| --- | --- | --- | --- |
| 2026年9月、既定（T1〜T4、月4便以上、無向） | 3,363 | 31,937 | 2.3 秒（正確計算） |
| 2026年5月、既定 | — | — | 1.9 秒 |
| 2026年8月、全路線（月1便以上）、有向 | 4,052 | 103,036（方向別） | 3.9 秒（正確計算） |

- 計算は Web Worker で行い、計算中も画面は操作できます。進行状況（%）を表示します。
- 条件を変えると、計算中の古い Worker を止めて新しい計算を始めます。古い条件の結果を新しい条件の結果として表示することはありません（計算中は結果を隠します）。
- 同じ条件の結果は最大8件までキャッシュします（主分析と比較で別々）。
- 最も重い条件（全路線・有向）の計算後、メインスレッドの JS ヒープは約 179 MB（地図と Explore のデータを含む）でした。
- GitHub Pages と同じサブパス（`/1090web/`）で本番ビルドを配信し、Research Mode、Worker、研究用データの読み込み、URL からの比較条件の復元を確認しました。

## 8. 現時点の制約（未実装・注意）

- 分析は1か月単位です。複数月をまとめたネットワークは未実装です。
- 重み付きの最短経路（便数の逆数などを距離とするもの）は実装していません。ホップ数だけです。
- 研究モードの結果（例：T1 だけのネットワーク、有向、地域の絞り込み）を地図に直接描くことはできません。「地図で表示」は Explore の絞り込みで近い条件を再現し、できない条件を一覧で示します。
- 比較 CSV は接続先空港数（次数）の上位20についてだけ出力します。画面上ではすべての指標を比較できます。
- 外部照合は、Phase 7 の主な条件（BTS：航空会社照合あり・全区分、ANAC：Dados Estatísticos の定期便）だけを公開しています。
- 国単位の日別の観測状況は、データセットに国別の日別集計がないため表示できません（大陸と全世界のみ）。
- 継続性は根拠区分ごとに数えていますが、航空会社・分類の絞り込みとは独立です。
- 研究モードの画面配置は暫定的です。スマートフォン幅では縦に並べるだけで、使い勝手は検証していません。
- 運航形態（定期・チャーター・ビジネス機）の区分はありません（Phase 7 の調査どおり、推測では分類しません）。
