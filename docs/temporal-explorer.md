# 時間軸エクスプローラー（Temporal Network Explorer）

Explore Mode と Research Mode で、2026年1〜9月の観測データを日・時間単位の任意の期間で見るための機能です。データの形式は [temporal-data-model.md](temporal-data-model.md)、実装の経緯と実測値は [phase9b-report.md](phase9b-report.md) にあります。

## 使い方

### Explore Mode

1. 画面下のタイムラインの左にある「月次／時間窓」で「時間窓」を選びます（観測データのときだけ表示）。
2. 「期間」で時間窓の種類を選びます。

| 期間 | 時間窓（UTC、[開始, 終了)） |
| --- | --- |
| 1日（UTC） | 選んだ日の 00:00 から 24 時間（既定） |
| 暦月 | 選んだ日を含む月の 1 日 00:00 から翌月 1 日 00:00 |
| 直近7日／24時間／6時間／1時間 | 選んだ日時で終わる 7 日／24／6／1 時間 |
| 任意の期間 | 開始・終了を 1 時間単位で指定 |

3. 「日付（UTC）」「時刻（UTC）」で日時を選びます。スライダーでも動かせます。スライダーの下の帯は表示中の期間（青）と、収集欠損の疑いのある日（橙）・通常と異なる日（灰）を示します。
4. ◀ ▶ で「移動幅」（1時間・6時間・1日・7日。暦月は1か月）ずつ動かします。▶（再生）で自動的に進みます。速度は遅い（2.5秒）・標準（1.2秒）・速い（0.5秒）。次の期間の集計が終わってから次へ進むので、途中の期間が飛ばされたり、古い結果が表示されたりしません。データの最後で止まります（「ループ」をオンにすると先頭に戻ります）。⏮ で先頭に戻ります。
5. 「時刻の基準」で「航跡開始時刻のある便のみ」を選ぶと、航跡終了時刻で数えた便を除きます。除いた便数と割合が表示されます。
6. 「比較対象」で同じ長さの別の期間（直前の期間、1日前、7日前）と比べます。地図の色分けと詳細パネルは月次の比較と同じです。
7. 地図・地球儀、絞り込み、空港の選択、路線の強調はすべて月次と同じように動きます。「月間便数」は「期間内の便数」に変わります。
8. 詳細パネルの下に「時間変化」（1時間または1日ごとの便数・運航路線数・選んだ空港の接続空港数）と「時刻の品質」が出ます。
9. 「Research Modeで分析」で、表示中の期間をそのまま Research Mode に渡します（便数の下限は 1 になります）。

URL に期間が残るので、そのまま共有できます。

```
?time=temporal&tc=2026-03-10T12:00Z&tw=rolling6h&ts=1h&tb=start&tcmp=previous&tsp=fast&tl=1
?time=temporal&tw=custom&tcs=2026-03-10T18:00Z&tce=2026-03-11T06:00Z
```

| パラメーター | 意味 |
| --- | --- |
| `time=temporal` | 時間窓の表示（ないときは月次） |
| `tc` | 選んだ日時（UTC、`YYYY-MM-DDTHH:MMZ`） |
| `tw` | 期間：`month`・`rolling7d`・`rolling24h`・`rolling6h`・`rolling1h`・`custom`（なし＝1日） |
| `tcs`・`tce` | 任意の期間の開始・終了 |
| `ts` | 移動幅：`1h`・`6h`・`7d`（なし＝1日） |
| `tb=start` | 航跡開始時刻のある便のみ |
| `tcmp` | 比較：`previous`・`day`・`week` |
| `tsp`・`tl=1` | 再生速度（`slow`・`fast`）、ループ |

UTC 以外の時差の付いた日時（`+09:00` など）は読み込まず、無視します。

### Research Mode

分析条件の「期間」で「暦月」と「時間窓（UTC）」を切り替えます。時間窓では開始・終了（UTC）と時刻の基準を指定します。

- 分析は日別ファイルを集計した同じ期間のネットワークで行います（Explore で見ていたものと同じ便）。
- 便数の下限の意味は「選択期間内に観測された路線ごとの便数」です。
- 「比較」では、同じ長さの直前の期間・1日前・7日前と比べられます。
- 概要の「1日あたり」は、時間窓では「1時間あたり」になります（短い期間を1日に引き伸ばしません）。
- 24時間未満の期間では、中心性などがその数時間の便だけを表す注意を表示します。
- 外部統計（月次）との照合は時間窓では行いません（「時間窓のため照合していない」と表示）。
- CSV には `window_start_utc`、`window_end_utc`、`time_basis_filter` の列が加わります（暦月の CSV の列は Phase 8 と同じ）。JSON の `temporal` には時間窓と条件（`datasetId`、`startTimeUtc`、`timeBasisFilter`、`selectedAirports` など）を記録し、読み込むと同じ条件が復元されます。データセットの版が違う場合は警告します。
- URL：`rws`・`rwe`（開始・終了）、`rwb=start`、`rwp`（期間の種類）、`rwst`（移動幅、ミリ秒）。
- 「地図で表示」は Explore の時間窓（任意の期間）で同じ期間を開きます。

## 観測品質の表示

時間窓ごとに次の状態を区別して表示します（`src/temporal/quality.ts`）。

| 状態 | 条件 | 表示 |
| --- | --- | --- |
| A 観測ゼロ | データはその時間を含むが便がない | 観測された便はありません |
| B 収集欠損の疑い | Phase 6B で収集欠損と判定された日の、世界の便数が 100 未満の時間 | 欠損の時間数と日付。「観測の欠落であり、航空交通の停止ではない」 |
| C ファイルなし | 日別ファイルがない日 | 該当日 |
| D 読み込み失敗 | 日別データを読み込めなかった | 数値は不完全 |
| E 絞り込み後ゼロ | 世界では便があるが、絞り込み条件に合う便がない | 世界の便数 |

2026年5月5日 00:00〜5月7日 18:00 UTC（66時間）は B として表示されます。時間変化の図では、欠損の時間帯を橙で塗ります。

## データの流れ（Phase 9C への準備）

```
日別ファイル (public/data/<dataset>/temporal/days)
  → 時間窓の選択      src/temporal/window.ts      TemporalSelection → TimeWindow
  → 観測ネットワーク  src/temporal/aggregate.ts   WindowAggregator → MonthData / ResearchMonth
  → [シナリオ変換]    src/temporal/scenario.ts    型のみ（未実装）
  → 分析              domain/networkView・research/
  → 表示              地図・地球儀・パネル
```

集計は Web Worker（`temporal.worker.ts`）で行い、元のデータは変更しません。将来のシナリオ変換は、集計結果（行の配列）を受け取って新しい配列を返す関数として、集計と分析の間に入れる想定です。`ScenarioEvent` には `isHypothetical` があり、安全勧告（`airspace_advisory`）と閉鎖（`airspace_closure` など）を別の種類にしています。架空のイベントは同梱していません。
