# 研究結果の検証（Phase 9I）

Phase 9A〜9H の主な計算を、別の実装で計算し直した記録です。「既存のテストが通る」ことと「独立に検証できた」ことは分けて書いています。同じパイプラインの 2 つの出力が一致しただけの場合は、「整合性の確認」と書き、独立の検証とは扱いません。

スクリプトは `pipeline/research_validation/`、結果は `data/quality/validation-9i-*.json` にあります。再実行の方法は [research-reproducibility.md](research-reproducibility.md) にあります。

### 収集停止（2026年5月5〜7日）

- 2026-05-05 00:00〜05-07 17:00 UTC の 66 時間に、世界全体で 6 便しか観測されていません（通常は約 27 万便）。全地域で同時に止まっているので、収集停止です。航空交通の停止ではありません。
- 再開直後の 05-07 18:00 は、通常の約 2 倍（9,327 便）が記録されています。
- 2026-05-04 は、12 時（584 便）と 16〜18 時（1,373・1,135・434 便）が通常の 1〜4 割です。ただし収集停止（通常の 5% 未満）とは判定されず、「原因不明の低下」です。イベント研究の「収集停止の日を除く」では除かれません。
- 時間の表示（探索の時間窓）は、収集停止の時間帯に警告を出します（ブラウザで確認）。

## 3. 重要空港の順位と不確実性（9E）

| 項目 | 内容 |
| --- | --- |
| 対象 | Systemic・Spillover、順位、Spearman・Kendall、上位 k |
| 期待される性質 | 順位と順位相関は同じ値（1e-12 で丸めた値）に基づき、厳密には等しい値は同順位になる |
| 独立の方法 | 保存された値から scipy で再計算（`experiment_ties.py`）。8 空港の値を独立の実装で再計算 |
| 一致しなかった値 | 全空港を候補にした実験で、保存された Spearman が同順位を正しく扱った値より小さい：Systemic と Spillover 0.68 → 0.76、近似の欠測実験 0.45〜0.70 → 0.91〜0.99、近似の感度分析 0.13〜0.56 → 0.58〜0.90。157 空港の厳密な実験では T1 のみ・閾値 10 だけ 0.25 → 0.22 |
| 原因 | Spearman・Kendall を丸めていない値で計算していた。厳密には 0 の Spillover（末端の空港）が ±1e-17 の誤差を持ち、同順位が誤差の大小で並べられていた |
| 修正 | Python・TS とも、順位相関を丸めた値で計算（methodVersion 9e.2）。回帰テストを追加 |
| 許容誤差 | 値は 1e-9（保存値は 9 桁に丸められている） |
| 結論 | 上位 k の一致・相対誤差・157 空港の結論は変わらない。全空港の順位相関は訂正 |
| 未解決 | 実験そのものは 9e.2 で再実行していない。157 空港の結果は、全 3,883 空港の安定性ではない。基準の上位から選んだ候補なので全体より安定に見えやすく、その偏りは評価していない |

### 近似の誤差と欠測によるばらつき

- 近似（起点のサンプル）の誤差と、欠測・条件によるばらつきは別のものです。
- 157 空港の結果はすべて厳密計算なので、近似の誤差を含みません。
- 全空港の近似の実験は、起点を固定したうえでの比較で、近似の誤差を含みます。画面と報告では「近似」と表示しています。

### 大陸の分類

Phase 9F の修正（空港ごとに大陸を決める）が地域別の欠測モデルに使われていることを確認しました（`march-missing-regional-exact-v2`、`continentRule: airport-v1`）。修正前の結果を読み込むと警告が出ます。

| 項目 | 内容 |
| --- | --- |
| 対象 | 人口メッシュの島への割り当て、重複、空港停止の前後の到達可能性 |
| 期待される性質 | 各メッシュは 1 つの島に 1 回だけ。島の人口は国勢調査と一致。「毎日の便で行けなくなる」と「まったく行けなくなる」を区別 |

### 5.2 DiD の監査

- **対照群**：東南アジア 6 か国です。対象地域と周辺国を発着する便は除いており、処置群との重複はありません。ただし湾岸のハブは東南アジアと欧州の間の便の一部を担っており、比較対象群自体も −8〜−10% 変化しています。同じ危機の影響を受けていない保証はありません。
- **水準差**：前の期間の対象地域の便数は、比較対象群の 0.71 倍（11 か国）から 0.03 倍（クウェート）です。対数の差で比べているので水準そのものは差し引かれますが、小さな系列ほど 1 便の重みが大きくなります。
- **季節性・曜日**：曜日の構成は前後で同じです。前年のデータがないため、季節性は確かめられません。
- **推定量**：log((後の平均+1)/(前の平均+1)) の、対象地域と比較対象群の差です。表示は exp(差) − 1 です。9G のプラセボは日ごとの log 比の平均という別の量で、実際の値と比べるべきものではありませんでした。9I で同じ量に揃えました。
- **自己相関と標準誤差**：日ごとの便数には自己相関があり、OLS の標準誤差は不確かさを過小に見積もります。Newey-West に変えると、UAE の比の事前トレンドは確認を満たさなくなります。
- **検出力**：14 日の系列で |t| < 2 であっても、傾きがないことの弱い根拠にしかなりません。
- **結論**：形式的な確認を満たすことは因果効果の根拠になりません。9I では、確認の結果にかかわらず値を「比較対象群に対する変化（記述的）」として表示します。確かめていないこと（比較対象群への影響、季節性、同時期の出来事、受信網、検出力）も一覧にしました。

### 5.3 事前トレンドと時間関係

11 か国の観測便は次のように動きました。

| 時期 | 観測便 |
| --- | --- |
| 2/1〜16 | 1 日 4,800〜5,200 便 |
| 2/17〜18 ごろから | 4,400〜4,800 便 |
| 2/27 | 1 時間 113〜240 便 |
| 2/28 00〜08 UTC | 1 時間 107〜191 便 |
| 2/28 09 UTC 以降 | 1 時間 22〜56 便 |

これをもとに、次の 4 つを区別します。

1. **2月17〜18日ごろからの減少**：前の期間（2/14〜27）の中の変化で、2月28日の出来事では説明できません。原因は特定していません。
2. **現地日付と UTC の境界**：UAE（UTC+4）の日付だけのイベントは、UTC の 2/27 20:00 から始まります。前の期間に重なるのは最後の 4 時間だけです。イベント調査では「時差で数時間だけ重なる」と表示します。
3. **2月28日当日**：比較から除いています（イベント日）。この日には出来事の前後の時間が混ざります。
4. **3月1日以降**：後の期間です。

9H 報告の「R0 の前の減少の一部は各国の措置と重なる」は 1 と 2 を混同した誤りで、訂正しました。

### 5.4 プラセボ

- プラセボの日は 7 日ごとに過去へさかのぼって選び、後の期間がイベント日にかからないものだけを使います。
- 14 日の窓では、系列（イベント前 60 日、データは 2026-01-01 から）の中で 6 日を調べ、2 日を除き、有効なのは 4 日です。
- 「0 / 4」は「0 / 100」と同じ強さの根拠ではありません。4 日では、割合は 0 の次が 1/4 で、約 20% より小さい p 値に当たる確かさは示せません。
- 画面には件数と、この注意を表示します。

### 5.5 イベントの時刻と記録

- 発生日、発生時刻、発表日時、発効日時、保存版で初めて確認した日時は、別々に記録されています（9H）。
- 保存版の時刻は発表の時刻ではなく、その上限として表示しています。
- 日付だけの時刻は 00:00 UTC に置かれません。固定の時差の地域は時差を引いた UTC の 1 日、夏時間のある地域は「時差が不確か」です（テストで確認）。
- 出典の SHA-256 は、取得した文書が同じであることを示すだけです。内容の解釈や出来事の真実性は保証しません。
- 次の 3 件について、記録の時刻・範囲を取得した文書の本文と照合し、一致を確認しました。
  - GCAA Safety Decision 2026-03：発行日 2026年2月28日、無人機と軽スポーツ機の承認の即時停止。
  - FAA SFAR 77：FL320 未満、米国の運航者、2024年10月16日発効、2027年10月26日まで。
  - EASA CZIB 2026-03 の現行版（R14）：発行日 28/02/2026、対象 11 か国、2月28日の攻撃と報復の記述。
- ほかのイベントの記録の照合は 9H の作業時のままで、9I では再確認していません。
- 報道だけのイベントは「未検証」のままです。
