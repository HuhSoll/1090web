# 1090web

世界の航空ネットワークを視覚化、シミュレーションするWebサイトです。

空港を選ぶとそこから伸びる路線だけが浮かび上がり、国や航空会社、旅客／貨物、便数で絞り込みながらネットワークの形を眺められます。月ごとのデータを切り替えたり、自動再生して変化を追ったりもできます。

2つの月を比べると、路線ごとの増減が色で表示されます（青が増加、オレンジが減少）。観測できた日数は月によって違うので、比較は1日あたりの便数で行います。見ている月・比較・絞り込み・選んだ空港は URL に残るので、そのまま共有できます。

「安全情報」をオンにすると、EASA（欧州航空安全機関）が出している紛争地域の注意喚起を、その月に有効だった国に重ねて表示します。注意喚起は運航停止を意味しないので、路線の表示は変えていません。

データは、ADS-B（航空機が発信する位置情報）の受信記録から作られた 2026年1〜9月の便データを月ごとに集計したものです。公式の時刻表ではなく、受信網が手薄な地域では観測できない便があります。空港を航跡から確認できなかった便は「便名から推定」として区別し、画面で切り替えられます。データの作り方と品質は [docs/pipeline.md](docs/pipeline.md) にまとめています。

## 研究モード

画面右上の「研究」に切り替えると、観測された航空ネットワークを条件を決めて分析できます。

- 月、国・地域、空港、航空会社コード、機材の分類、月間便数の下限、観測された月数、空港判定の根拠（T1〜T4）、有向／無向を指定
- 次数、重み付き次数、媒介中心性、調和近接中心性、PageRank、連結成分、密度、クラスタ係数を計算（Web Worker で計算するので画面は止まりません）
- 空港・路線のランキング、国・地域の集計、月や閾値・根拠区分・地域を1つ変えた比較（順位の相関、上位20の一致率）
- データ品質（収集停止、異常日、根拠の構成）と、米国・ブラジル・日本の公式統計との条件付きの照合結果を表示
- 結果を CSV、条件と出典を JSON で保存。JSON や URL から同じ条件を復元できます

## 時間窓（日・時間単位）

タイムラインの「月次／時間窓」で「時間窓」を選ぶと、2026年1〜9月の任意の日・時間帯のネットワークを表示できます（時刻はすべて UTC）。

- 1日、暦月、直近7日・24時間・6時間・1時間、任意の期間を選び、1時間〜7日の幅で前後に動かしたり再生したりできます
- 便はその期間に記録が始まった便（航跡の開始時刻、なければ終了時刻）で数えます。離着陸時刻ではありません。「航跡開始時刻のある便のみ」にも切り替えられます
- 同じ長さの直前の期間・1日前・7日前と比べられ、1時間または1日ごとの便数・路線数の変化を表示します
- データの収集が止まっていた時間（2026年5月5〜7日）は警告し、航空交通の停止とは区別します
- 表示中の期間をそのまま研究モードで分析できます

使い方は [docs/temporal-explorer.md](docs/temporal-explorer.md)、データ形式は [docs/temporal-data-model.md](docs/temporal-data-model.md) にあります。

## シミュレーション

空港や路線が使えなくなったと仮定して、ネットワークのつながりがどう変わるかを調べられます。空港の詳細パネルの「この空港の停止をシミュレーション」か、上部の「シミュレーション」から始めます。

- 複数の空港、路線（片方向・双方向）を停止し、開始・終了の日時（UTC）を指定できます。停止はタイムラインに帯で並び、ドラッグで編集、再生で発生・終了・再開の順に変化を追えます（元に戻す・やり直す付き）
- 「構造」は期間中ずっと使えないと仮定した分析、「時刻照合」は便の記録の時刻が停止の時間に入るものだけを除く分析です（出発は航跡開始、到着は航跡終了で判定）
- 基準の期間を固定するか、時間窓の表示に連動させるかを選べます
- 失われた接続、ほかの空港への波及（2・3ホップ以内の到達、ネットワーク効率）、空港ごとの影響、代替経路と経路が失われた原因を表示し、地図・地球儀には変化した接続と影響を受けた空港を中心に表示します（「停止前を見る」で観測ネットワークと切り替え）
- 影響の時間変化をタイムラインの下にグラフで表示します
- シナリオは JSON で保存・共有でき、結果は CSV・JSON で出力、研究モードで中心性を比較できます

結果は観測された ADS-B のネットワークの構造分析で、欠航数や運航の予測ではありません。使い方は [docs/simulation-guide.md](docs/simulation-guide.md)、計算方法は [docs/simulation-methodology.md](docs/simulation-methodology.md) にあります。

## 実験（結果の頑健性）

研究モードの「実験」タブでは、空港を1つずつ止めたときの影響の順位が、ネットワークの作り方や観測の欠けでどれだけ変わるかを調べられます。シミュレーションの「この結果の頑健性を検証」からも始められます。

- 影響は2通りで測ります。止めた空港を含む全体の効率の低下（Systemic）と、ほかの空港どうしの効率の低下（Spillover）です
- 感度分析：ティア（T1〜T4 / T1〜T3 / T1）、便数の閾値、有向・無向、機材の区分を変えて順位を比べます
- 欠測の実験：一様・地域別・低頻度路線の3つのモデルで便をランダムに取り除き、ネットワークを作り直すことを繰り返します（シード固定で再現可能）
- 順位の相関（Spearman・Kendall）、上位 k の一致、空港ごとの順位の幅、影響の分布、地図での比較を表示し、CSV・JSON で保存できます
- 全空港の厳密計算や 100 回以上の試行は Python のバッチで実行し、結果ファイルを研究モードで読み込めます（ファイルはブラウザの中だけで使います）

結果は条件や想定したモデルによる違いを示すもので、信頼区間ではありません。使い方は [docs/experiment-guide.md](docs/experiment-guide.md)、計算方法は [docs/experiment-methodology.md](docs/experiment-methodology.md) にあります。

## 離島の依存性（沖縄パイロット）

研究モードの「離島の依存性」タブでは、離島の空港が使えなくなったとき、住民が那覇や本土へ行く手段がどう変わるかを調べられます。シミュレーションで離島の空港を止めたときの「地域住民への影響を調べる」からも開けます。

- 対象は宮古島（橋でつながる伊良部・下地・池間・来間を含む）、石垣島、西表島、与那国島、多良間島、南大東島、北大東島です
- 人口は 2020年国勢調査の 250 m メッシュ、道路は国土数値情報、航空・船舶の路線は沖縄県の資料（2025年）を使います。メッシュから道路で空港・港へ行き、定期便に乗る経路を計算します
- 停止前後で、行けなくなる住民、時間が増える住民、残る手段（橋の先の空港、船、なし）を、便の頻度（毎日／週1以上／回数を問わない）の条件ごとに数えます
- 地図でメッシュごとの変化を表示し、Phase 9E の Systemic / Spillover の順位と並べて比べられます。CSV・JSON で保存できます

時刻表を使わないモデルのため、出発までの待ち時間・座席数・欠航は含みません。琉球エアーコミューターの路線は ADS-B のデータにないため、県の資料から入れています。使い方は [docs/island-dependency-guide.md](docs/island-dependency-guide.md)、計算方法は [docs/island-dependency-methodology.md](docs/island-dependency-methodology.md)、データの出典は [docs/island-data-sources.md](docs/island-data-sources.md)、結果は [docs/phase9f-report.md](docs/phase9f-report.md) にあります。
