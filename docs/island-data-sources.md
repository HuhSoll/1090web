# 離島の依存性：データの出典（Phase 9F）

研究モードの「離島の依存性」と `pipeline/islands/` が使うデータの一覧です。ダウンロードしたファイルは `pipeline/islands/sources.lock.json` に URL、取得日時、サイズ、SHA-256、ライセンスを記録しています。元のファイル（`data/raw/islands/`）は Git にも GitHub Pages にも入れていません。公開しているのは、下の「公開する派生データ」だけです。

計算方法は [island-dependency-methodology.md](island-dependency-methodology.md)、使い方は [island-dependency-guide.md](island-dependency-guide.md)、結果は [phase9f-report.md](phase9f-report.md) にあります。

## 個別の注意

### 人口（e-Stat）

- ファイルには人が住むメッシュだけが入っています。6 つの 1次メッシュ（3622・3623・3624・3724・3725・3831）で 1,853 メッシュ、109,119 人です。
- **秘匿処理**：`HTKSYORI` が 1 または 2 のメッシュ（1,184）では、年齢・性別の内訳が「*」になり、隣のメッシュ（`HTKSAKI`）に合算されています。人口総数（T001142001）は全メッシュで公表されています。このため、総数をそのまま足しても二重計上になりません。
- 照合：1次メッシュ 3725 の合計 52,931 人は宮古島市の 2020年国勢調査人口と一致します。島への割り当て後の石垣島 47,637 人（石垣市）、与那国島 1,676 人（与那国町）、南大東島 1,285 人（南大東村）も各市町村の 2020年の人口と一致します。
- 基準年は 2020年です。航空・船舶は 2025年、観測便は 2026年で、年がそろっていません。

### 道路（N13）

- 道路中心線の線データで、経路探索用のネットワークではありません。端点が一致する線どうしだけをつなぎ、交差していても頂点を共有しない線（立体交差など）はつなぎません。
- 除いたもの：種別が庭園路・徒歩道・石段の線（4,922 本）。状態が「建設中」の線も除く設定ですが、対象の範囲にはありませんでした。
- 「橋・高架」（`N13_004 = 2`）の指定は、長い橋の全長には付いていません（伊良部大橋など）。そのため、島の間のつながりは属性ではなく形から判定しています（方法の 2.3 節）。
- 1次メッシュをまたぐ線は、境界の頂点の座標が一致するのでつながります。

### 行政区域（N03）

- 市町村ごとのポリゴンで、島ごとに別の地物になっています。島の識別子は、設定ファイルの代表点を含むポリゴンで決めます（`pipeline/islands/okinawa-pilot.json`）。
- 計算した面積は公表値とほぼ一致します（宮古島 158.8 km²、石垣島 222.7 km²、西表島 290.2 km²、与那国島 28.9 km²）。
- 港の埋立地などが別のポリゴンになっている場所があります（与那国島の祖納など）。メッシュの割り当ての規則で扱っています。

### 航空・船舶（沖縄県の資料）

- 区間ごとに、距離、機種、所要時間（分、幅がある）、運航回数（往復で 1。日・週・年）を記録しています。時刻表（出発時刻・曜日）はありません。
- 航空路線は資料の 65 ページ、旅客定期航路は 72〜75 ページ（事業者・航路・距離・所要時間・運航回数）から転記し、設定ファイルにページを記録しました。
- 南大東〜北大東の航空路線は「令和6年7月にて運休」と注記されているため、運休として扱います。
- 季節運航の路線（石垣〜伊丹、福岡〜下地島の7〜8月）は既定では含めません。
- 大東航路（大東海運）は「那覇(泊)～南北大東」、405 km、16:00、年 60 回です。2 島目までの所要時間と南北大東間の所要時間は資料にないため、「不明」として扱います。
- 石垣〜与那国のフェリーは週 2 回、所要 3:50 です。運航曜日は資料にないため使いません（旅行記事の曜日は検証できないため使っていません）。
- 多良間島の港は季節で前泊港と普天間港（多良間港）を使い分けます。大東の各島では天候で着岸する港が変わります。どちらも港のグループとして扱い、遠いほうの港までの時間で計算します。

### 船舶のほかの候補（使っていないもの）

| データ | 理由 |
| --- | --- |
| 国土数値情報 定期旅客航路（N09） | 2012年度版で古く、利用条件が「非商用」のため、ODbL の公開データに含められない |
| 国土数値情報 港湾（C02） | 2014年度版、利用条件が「非商用」。港の位置は OSM を使用 |
| 国土交通省 Project LINKS の一般旅客定期航路事業データ、標準的なフェリー・旅客船航路情報フォーマット（GTFS 系） | 今回は取得していない。時刻表を使うモデル B の候補 |
| 各船会社の公式時刻表 | 今回は取得していない。運航日・出発時刻を使うには事業者ごとの確認が必要 |

### 港（OpenStreetMap）

- フェリーターミナルのノードがある港はその位置を使い、ない港（大東の各港、多良間の港）は名前に「港」を含む港湾のノードを使いました。ノード ID は設定ファイルにあります。
- 港の位置の誤差は、島の中の道路の時間（数分）にしか影響しません。

### 観測便（ADS-B）

- 2026年3月の観測で、琉球エアーコミューター（RAC）の便は一つもありません。与那国・多良間・南大東・北大東の空港には観測便がなく、1090web の空港一覧にもありません。宮古〜石垣も観測がありません。
- 観測がある路線でも、往復の数は県の資料の 85〜97% です（那覇〜宮古：資料 98 往復／週、観測 84）。石垣〜成田は成田→石垣の 31 便だけが観測され、逆方向は 0 便でした。
- 航跡の時間は海上で途切れるため、所要時間には使いません（那覇→石垣の航跡時間の中央値は 15 分、資料では 60 分）。
- 那覇〜本土の路線は県の資料にないため、観測便で「路線がある・週何往復か」だけを使い、所要時間は不明として扱います。
