# 離島の依存性：計算方法（Phase 9F）

研究モードの「離島の依存性」と `pipeline/islands/` の計算方法です。Python（`pipeline/islands/access.py`）とブラウザ（`src/islands/access.ts`）は同じ手順で計算し、公開データの 10 の条件で結果が一致することをテストしています。

データの出典は [island-data-sources.md](island-data-sources.md)、使い方は [island-dependency-guide.md](island-dependency-guide.md)、結果は [phase9f-report.md](phase9f-report.md) にあります。

## 1. 何を測るか

ある空港が使えなくなったとき、島の住民が目的地（那覇・福岡・鹿児島・東京）へ行く手段がどう変わるかを、250 m メッシュの居住人口で数えます。

- 「空港がある」と「住民がその空港を使える」は別に扱います。住民はメッシュから道路で空港・港まで行き、そこから定期便に乗ります。
- 「空港が閉鎖される」と「島から出られない」も別です。船や橋の先の別の空港が残っていれば、時間は増えても行けます。
- 航空ネットワークへの影響（Phase 9E の Systemic / Spillover）とは別に計算し、足し合わせません。

## 2. 交通ネットワーク

### 2.1 ノード

| 種類 | 識別子 | 例 |
| --- | --- | --- |
| 島 | 設定ファイルの島 ID | `miyako`、`irabu`、`iriomote` |
| メッシュ | 2020年国勢調査の 5次メッシュコード | `3725015944` |
| 空港 | ICAO コード | `ROMY`、`ROYN` |
| 港 | `P_` で始まる ID | `P_HIRARA`、`P_KUBURA` |
| 港のグループ | `G_` で始まる ID（季節や天候で使い分ける港） | `G_TARAMA`、`G_MDAITO` |
| 目的地 | 目的地 ID と、そこに着いたとみなすノード | `naha` = 那覇空港・泊港 |

島と空港・港・行政区域の識別子は分けています。橋でつながる島（宮古・伊良部・下地・池間・来間）も別の島として残し、道路のつながりで結びます。

### 2.2 メッシュの島への割り当て

1. メッシュの中の 9 点（中心、四隅から 10% 内側、各辺の中点）が、どの陸地のポリゴン（N03）に入るかを調べます。
2. 最も多くの点が入るポリゴンをそのメッシュの島にします。同数のときは、パイロットの島、中心が入るポリゴン、ポリゴンの番号の順に決めます。
3. 9 点のどれも陸地に入らないメッシュは「海上」とし、島を割り当てません（今回は 0 人）。

人口は 1 メッシュにつき 1 つの島に全部入れるため、二重計上はありません。パイロット以外の島（竹富・小浜・黒島・波照間・大神など）の 1,743 人は「対象外の島」として数え、計算には入れません。

### 2.3 道路

- N13 の線の頂点を座標（1e-7 度で丸め）で一つにまとめ、隣り合う頂点を辺でつなぎます。端点を共有しない線どうしはつなぎません。
- 所要時間は、幅員ごとの仮定の速度で計算します（3 m 未満 20 km/h、3〜5.5 m 30、5.5〜13 m 40、13 m 以上 50、不明 30）。
- **島の間のつながり**：頂点ごとに、どの島の陸地にあるか（海上・パイロット以外の陸地を含む）を調べます。海上や別の陸地を通る辺の連なりのうち、両端がパイロットの 2 つ以上の島にあるものを「島の間をつなぐ辺」とします。橋の属性は長い橋の全長に付いていないため使いません。この方法で、来間大橋（1.7 km）、伊良部大橋（約 4.3 km、取り付け道路を含む）、池間大橋（1.8 km）と、伊良部島〜下地島の間の 6 つの小さな橋が見つかります。海に出て同じ島に戻る海岸の道路はつながりに数えません。
- 「橋を使わない」の条件では、島の間をつなぐ辺を除いたグラフで計算します。
- メッシュは、同じ島にある最も近い道路の頂点（1,500 m 以内）につなぎます。直線距離を時速 15 km で換算します。空港・港も同じ島の最も近い頂点（3,000 m 以内）につなぎます。
- 道路のグラフで各空港・港から最短時間を求め、メッシュから行ける空港・港とその時間を `meshes.json` に記録します（橋あり・なしの 2 通り）。空港・港どうしの道路の時間も記録します。

### 2.4 定期便（航空・船舶）

- 区間、所要時間（分の幅）、運航回数（往復／週）、状態（運航・季節運航・運休）を設定ファイルに持ちます。沖縄県の資料から転記し、ページを記録しています。
- 所要時間は幅の中央の値を使います。資料にない所要時間は「不明」（`null`）のままにし、推測で埋めません。
- 那覇〜本土の航空路線は、ADS-B の観測便から「路線がある・週何往復か」だけを入れ、所要時間は不明です。
- 港のグループへの道路の時間は、グループの中で最も遠い港までの時間にしています（都合のよい港に着くと仮定しないため）。

### 2.5 手続き・乗り継ぎ（仮定）

| 場面 | 仮定 |
| --- | --- |
| 最初の便に乗る（航空） | 30 分 |
| 最初の便に乗る（船） | 15 分 |
| 航空 → 航空 | 40 分 |
| 航空 ↔ 船 | 60 分 |
| 船 → 船 | 30 分 |

出発までの待ち時間は含めません。

## 3. アクセスの計算（モデル A：交通網の利用可能性）

時刻表を確認できていないため、今回はモデル A だけを実装しました。運航日・出発時刻・乗り継ぎを使うモデル B（時刻表を使う分析）は未実装です。

### 3.1 空港・港ごとの経路

各空港・港から目的地まで、条件に合う定期便と道路で次の 2 つを求めます。

1. **到達できるか**：所要時間を問わず、乗る便の数が最も少ない経路を探します。
2. **最短の時間**：所要時間が確認できる区間だけを使い、(ノード, 直前に乗った便の手段) を状態として最短時間を求めます。時間は「道路＋手続き・乗り継ぎ＋定期便の所要時間」です。

使える便の条件：

| 条件 | 内容 |
| --- | --- |
| 手段 | 航空・船舶のどちらを使うか |
| 便の頻度 | 「運航回数を問わない」、「週1便以上」、「毎日運航の便だけ」（週 7 往復以上） |
| 橋 | 島の間の橋を使うか |
| 季節便 | 7〜8月だけの便を含めるか（既定は含めない） |
| 停止 | 止める空港（その空港に出入りするすべての便）と、止める船の航路（代替交通の停止） |

### 3.2 メッシュの状態

メッシュから道路で行ける空港・港のそれぞれについて、「道路の時間＋その空港・港からの経路」を比べます。

| 状態 | 意味 |
| --- | --- |
| 行ける（`ok`） | 経路があり、時間を計算できる |
| 行けるが時間は未確認（`time-unknown`） | 経路はあるが、所要時間が不明の区間を使う。または、所要時間が確認できる経路より便の数が少ない経路があり、その所要時間が不明（このとき確認できる経路の時間は上限にすぎないため、時間として扱わない） |
| 行けない（`unreachable`） | 条件に合う経路がない |
| 計算できない（`no-access`） | 道路で行ける空港・港がない（西表島の船浮など、船でしか行けない集落 41 人） |

「行けない」と「計算できない」は別に数えます。

### 3.3 停止前後の比較

同じメッシュ・同じ人口で、停止前（何も止めない）と停止後を比べ、メッシュごとに次のどれかに分けます。

| 変化 | 判定 |
| --- | --- |
| 行けなくなる | 前は行けた（時間不明を含む）、後は行けない |
| 時間が増える | 前後とも時間を計算でき、0.5 分より長く増えた |
| 便が少ない経路になる | 前後とも時間を計算でき、時間は増えないが、乗る便の数が増えたか、経路の中で最も少ない便の運航回数が減った |
| 比較できない | 前後とも行けるが、どちらかの時間が未確認で、経路が変わった |
| 変化なし | 上のどれでもない |
| 計算できない | 前か後が「計算できない」 |

## 4. 指標

| 指標 | 定義 |
| --- | --- |
| 対象人口 | パイロットの島に割り当てた 2020年の居住人口（停止の前後で同じ） |
| 影響人口（Population Exposed） | 「行けなくなる」＋「時間が増える」＋「便が少ない経路になる」の人口 |
| アクセスの喪失（Accessibility Loss） | 「行けなくなる」の人口と、その割合。便の頻度の条件ごとに数える |
| 追加の移動時間（Additional Travel Time） | 「時間が増える」メッシュの増加分の、人口で重み付けした平均と最大。単位は分、待ち時間を含まない |
| 人口加重の影響（Population-Weighted Impact） | 時間が増えるメッシュの「人口 × 増加分」の合計（人・分） |
| 代替手段（Alternative Availability） | 停止後の経路で最初に乗る便（別の空港の航空便、船、なし）ごとの人口 |
| 時間の上限 | 指定した時間以内に行ける人口と、その時間以内でなくなる人口 |

- 行けなくなる人口は時間の平均に入れません（無限大の時間として平均することはしません）。
- 「この空港に何人が頼っている」という数字は、必ず目的地と便の頻度の条件を付けて示します。旅行の需要や患者搬送の需要の推計ではありません。
- 「搭乗する住民」は、停止前の経路でその空港を使う住民（船で別の島に渡ってから乗る住民を含む）です。

## 5. Phase 9E との比較

- **観測**：Phase 9E の厳密な基準（2026年3月、有向、T1〜T4、閾値 1、3,883 空港）の Systemic / Spillover の順位です。ADS-B で観測されていない空港（与那国・多良間・南大東・北大東）はこのネットワークにありません。
- **離島路線を補完**：観測ネットワークに、県の資料にあって ADS-B にない航空路線（13 弧）を加えたネットワークで、島の空港と那覇空港だけを厳密に計算しました。ほかの空港は計算し直していないため、位置は 9E の基準の分布に対する位置（値がより大きい空港の数 + 1）で、正確な順位ではありません。比較のためだけに使い、9E の結果とは混ぜません。
- 2 つの指標は単位も分母も違うため、合計した点数は作りません。表と、横軸に Systemic の位置、縦軸に毎日の便で行けなくなる住民（対数）を取った図で並べます。

## 6. 限界

- **待ち時間なし**：週 2 便のフェリーを使う経路の時間は、出発まで数日待つ時間を含みません。このため、便の頻度の条件（毎日・週1以上）を必ず併記します。
- **容量なし**：便の座席数を考えていません。宮古空港が止まったとき、下地島空港の 1 日 2 往復で宮古の住民全員が移動できるとは限りません。
- **欠航なし**：天候・機材による欠航、船の着岸できない日を扱いません。大東航路の年 60 回、石垣〜上原の高速船など、天候の影響が大きい航路があります。
- **仮定の速度・時間**：道路の速度と手続き・乗り継ぎの時間は仮定です。感度を [phase9f-report.md](phase9f-report.md) に示しています。
- **目的地の先**：那覇空港・泊港に着いた時点で「那覇に着いた」とします。那覇市内の移動、病院などの施設までの移動は含みません。
- **年の違い**：人口は 2020年、運航は 2025年、観測便は 2026年です。
