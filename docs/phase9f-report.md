# Phase 9F 報告：離島空港への依存性（Island Airport Dependency Lab）

沖縄県の離島をパイロットとして、離島の空港が使えなくなったときに住民の移動の手段がどう変わるかを計算する仕組みを作りました。あわせて、Phase 9E で見つかった大陸分類の不具合を直し、影響を受けた実験を計算し直しました。

- 計算方法：[island-dependency-methodology.md](island-dependency-methodology.md)
- 使い方：[island-dependency-guide.md](island-dependency-guide.md)
- データの出典：[island-data-sources.md](island-data-sources.md)

数値はすべて、2020年国勢調査の 250 m メッシュの居住人口と、沖縄県『離島関係資料（令和8年版）』の路線（航空は 2025年11月末、船舶は 2025年10月1日時点）に基づくモデル A（交通網の利用可能性）の結果です。出発までの待ち時間、座席数、欠航は含みません。旅行の需要や患者搬送の需要の推計ではありません。

## 1. 大陸分類の修正（Phase 9E の不具合）

### 原因と修正

- `pipeline/research_web.py` は、国ごとに「最初の空港」の大陸を国全体に使っていました。スペインはカナリア諸島の空港が先に来るため全体がアフリカに、ロシアは欧州の空港が先に来るため全体が欧州になっていました。
- 修正後は空港ごとに大陸を決めます（OurAirports の `continent`）。`quality.json` に次を追加しました。
  - `airportContinents`：国の多数派と大陸が違う空港（88 空港。カナリア諸島、ロシアの欧州側、ハワイなど）
  - `continents`：国の多数派の大陸（国を選んだときの地域の初期値だけに使用。同数のときはアルファベット順）
  - `multiContinentCountries`：複数の大陸にまたがる国と空港数（ES・RU・US・EG・GR・TR・CO・VE）
  - `continentRule: "airport-v1"`（判定の根拠）
- 修正で変わった国の多数派は ES（AF → EU）と RU（EU → AS）だけです。`quality.json` だけを作り直し（`research_web.py --only-quality`）、ほかの研究データは変えていません。
- ブラウザ（研究モードの地域の絞り込み・地域の集計、シミュレーションの地域別の集計、実験）と Python のバッチは、空港ごとの大陸を使います。
- 実験の結果には `dataset.continentRule` を記録します。古い規則の結果を読み込むと警告を出します（地域別のモデルや地域の絞り込みを使った結果には、数値が違うことを明記した警告）。
- 回帰テスト：同じ国で複数の大陸（スペイン・ロシア）、行の順序に依存しないこと、古いファイルの扱い、公開データでカナリア諸島が AF・マドリードとバルセロナが EU・ロシアの両側が分かれること。

### 影響を受けた 9E の実験

| 実験 | 影響 | 対応 |
| --- | --- | --- |
| 欠測 B 地域別（厳密、157 空港、10 試行） | 確率が大陸で決まるため数値が変わる | `march-missing-regional-exact-v2` として計算し直した（1,536 秒）。元の結果は消さずに残し、`continentRule` で区別 |
| 欠測 B 地域別（近似、全空港、20 試行） | 同上 | 計算し直していない。9E 報告の 9 節のとおり近似は結論に使っていないため |
| 感度分析・欠測 A・欠測 C | 大陸は表示（空港の行の `continent`）だけ。順位は変わらない | なし（読み込むと「大陸の表示が古い規則」と警告） |

## 4. 空港停止による人口・交通アクセスへの影響（C）

### 4.1 目的地：那覇（沖縄本島）

| 停止する空港 | 停止前にこの空港を使う住民 | 毎日の便で行けなくなる | まったく行けなくなる | 悪化（運航回数を問わない） | 追加の移動時間（平均 / 最大） | 停止後に残る手段 |
| --- | --- | --- | --- | --- | --- | --- |
| 宮古（MMY） | 49,380 | 1,054（多良間島） | 0 | 49,380 | +25 分 / +127 分 | 宮古群島の 48,326 人は橋で下地島空港へ（那覇便は 1 日 14 往復 → 2 往復）。多良間島は船で平良へ渡り下地島空港へ（週 6） |
| 下地島（SHI） | 4,582 | 0 | 0 | 4,582 | +11 分 / +20 分 | 伊良部・下地の住民は橋で宮古空港へ |
| 新石垣（ISG） | 49,822 | 49,822（石垣島 47,637・西表島 2,185） | 0 | 49,822 | +288 分 / +320 分 | 船で与那国へ（週 2）渡り与那国空港から那覇へ。実質的な代替ではない |
| 与那国（OGN） | 1,676 | 1,676 | 0 | 1,676 | +277 分 / +283 分 | 船で石垣へ（週 2、3 時間 50 分） |
| 多良間（TRA） | 1,054 | 1,054 | 0 | 1,054 | +104 分 / +108 分 | 船で平良へ（週 6、2 時間） |
| 南大東（MMD） | 1,285 | 1,285 | 0 | 1,285 | +883 分 / +890 分 | 船で那覇へ（年 60、16 時間） |
| 北大東（KTD） | 590 | 590 | 0 | 590 | +879 分 / +884 分 | 同上 |

- 追加の移動時間は「運航回数を問わない」条件で、出発までの待ち時間を含みません。週 2 便・年 60 便の船では、実際には数日〜1 週間以上の待ちが加わります。このため「毎日の便で行けなくなる」を併記しています。
- 「まったく行けなくなる」が 0 なのは、どの島にも何らかの船の経路が残るためです。宮古と下地島の両方が止まると、宮古群島と多良間島の 53,962 人がまったく行けなくなります（宮古〜那覇の旅客船はない）。西表島の船（大原・上原）が止まると 2,185 人がまったく行けなくなります。
- 大東の両島は、2024年7月に南大東〜北大東の航空路線が運休したため、隣の島の空港が代替になりません。それぞれの空港だけに頼っています。

| --- | --- | --- | --- |

| 新石垣 | 49,822 | 49,822 | 比較できない 51,485 |

- 本土へは多くの経路が那覇経由で、那覇〜本土の所要時間が不明なため「比較できない」が多くなります。所要時間の確認できる直行便の時間だけで比べると、実際より遅い経路を選んでしまうため、そうした場合は時間として扱っていません。
- 「毎日の便で行けなくなる」は所要時間に関係なく判定できるため、本土でも那覇と同じ結果です。

### 4.3 条件による違い（感度）

| 条件 | 結果 |
| --- | --- |
| 便の頻度 | 最も結果を変える条件です。新石垣の停止は、「毎日運航の便だけ」では 49,822 人が行けなくなり、「週1便以上」では全員が「時間が増える（+288 分）」になります |
| 橋を使わない | 宮古空港の停止で、宮古島の 47,676 人が行けなくなります（下地島空港へ行けないため）。下地島空港の停止では下地島の 93 人が行けなくなります（伊良部島には空港・使える港がない） |
| 船を使わない | 宮古の停止で多良間島（1,054 人）が行けなくなる以外は変わりません |
| 道路の速度 ×0.75 / ×1.5 | 宮古の停止の追加時間の平均：18 分 / 37 分（基準 25 分）。下地島：9 / 15 分（基準 11 分） |

| 乗り継ぎ 0 分 ・ 2 倍 | 与那国の停止：217 / 337 分（基準 277 分） |

仮定の値は追加の時間を数十分変えますが、「行けなくなる」人口と、代替手段の種類は変わりません。

### 見つかったこと

- **世界的な重要度は低いが、地域依存性は高い空港**：与那国・多良間・南大東・北大東。ADS-B の観測ネットワークには現れず、県の路線を補ってもSystemic は 3,883 空港中 3,235〜3,369 番目（下位 17%）、Spillover は 0 です。しかし停止すると、それぞれの島の住民全員（1,676・1,054・1,285・590 人）が、毎日運航の便で那覇へ行けなくなります。残るのは週 6〜年 60 回の船だけです。
- **新石垣**：Systemic は観測で 1,828 位と中位、Spillover は 0 です。停止すると石垣島と西表島の 49,822 人が、毎日の便で那覇・本土へ行けなくなります。今回の 7 空港で、影響を受ける人口が最も多い空港です。
- **宮古**：補完したネットワークで Systemic 288 番目・Spillover 234 番目と、7 空港で最も世界的な重要度が高い空港です。停止すると 49,380 人の時間が増えますが、橋の先の下地島空港が代替になり、毎日の便で行けなくなるのは多良間島の 1,054 人です。ただし那覇便は 1 日 14 往復から 2 往復になり、座席数を考えれば同じ人数は運べません。
- **航空ネットワーク上の重要度は同程度でも、住民に代替がある空港**：下地島。Systemic（1,734 位）は新石垣（1,828 位）より高い（国際線があるため）のに、停止しても伊良部・下地の住民は橋で宮古空港へ行けます（+11 分）。
- **Systemic・Spillover と住民の依存性の関係**：ほとんど関係がありません。Spillover は「ほかの空港どうしの行き来」が頼る度合いで、島の住民は止めた空港自身の利用者なので Spillover には入りません。また、9E のネットワークは空港を点として扱い、人口を持ちません。離島の空港の重要性は、9E の指標では測れない別の軸です。

## 6. 研究上の限界と次の課題（E）

### 限界

- **時刻表なし（モデル A のみ）**：出発までの待ち時間、曜日、乗り継ぎの成否を扱っていません。表示する時間は「指定した時刻に移動できる時間」ではありません。モデル B は未実装です。
- **容量・欠航なし**：座席数、天候による欠航、船の着岸できない日を扱っていません。大東航路や石垣〜上原の高速船は天候の影響が大きい航路です。
- **仮定の時間**：道路の速度、手続き、乗り継ぎは仮定値です（4.3 節）。
- **所要時間の欠け**：那覇〜本土、大東の 2 島目までと南北大東間の所要時間がありません。該当する経路は「比較できない」になります。
- **ADS-B の欠け**：RAC の路線は ADS-B のデータにありません。1090web の地図・研究モード・シミュレーションでは、与那国・多良間・南北大東は存在しない空港として扱われています。
- **目的地の先**：那覇空港・泊港に着いた時点までで、医療機関などの施設への移動は含みません。
- **年の違い**：人口 2020年、運航 2025年、観測便 2026年。
- **パイロットの範囲**：沖縄県の 11 島です。竹富町のほかの島、大神島などは対象外です。

### 次の課題

- 船の時刻表（Project LINKS、GTFS、各社）を取得し、運航日・出発時刻を使うモデル B を作る。
- 那覇〜本土の所要時間を公式の資料で確認する。
- 便の座席数（県の資料の旅客実績など）を使った容量の考慮。
- 奄美群島・五島列島・隠岐諸島への拡張（設定ファイルと 1次メッシュの追加）。
- 竹富町のほかの島（波照間空港は定期便なし）を加える。
