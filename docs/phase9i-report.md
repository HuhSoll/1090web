## 重大な問題（先に読んでください）

1. **Phase 9H の「差分の差分」は効果の推定値として支持できません。**
   - 9H は、UAE・カタール・クウェートで 6 つの確認を満たしたとして −77%・−97%・−98% を示しました。
   - 日ごとの便数の自己相関を考慮すると（Newey-West の標準誤差）、UAE の比の事前トレンドは t = −2.73 で、確認を満たしません。
   - 比較対象群自体も同じ期間に約 −9% 変化しており、プラセボは 4 日しかありません。
   - そもそも、確認をすべて満たしても平行トレンドの証明にはなりません。
   - 対応：表示を「比較対象群に対する変化（記述的）」に改め、効果の推定値としては扱いません（B1）。
2. **Phase 9H 報告の時間関係の記述は誤りでした。**
   - 9H 報告は「R0 の前の減少の一部は 2月28日の各国措置と重なる」と書きました。
   - 前の期間（2/14〜27）の減少は 2月28日より前に起きており、その日の出来事では説明できません。報告を訂正しました（B2）。
3. **Phase 9E の全空港の順位相関が過小でした。**
   - Spearman・Kendall を、順位と違って丸めていない値で計算していました。
   - そのため、厳密には 0 になる影響（±1e-17 の誤差）の同順位が、誤差の大小で並べられていました。
   - 主な影響は次のとおりです。
     - Systemic と Spillover の全 3,883 空港の Spearman：0.68 → 0.76
     - 256 起点の近似と厳密計算の Spillover の Spearman：0.52〜0.58 → 約 0.85
     - 近似（全空港）の実験の Spillover の Spearman：0.13〜0.70 → 0.58〜0.99
   - 157 空港の厳密な実験は、1 つの値（T1 のみ・閾値 10：0.25 → 0.22）を除いて変わりません（B3）。

### 検証の方法

既存のテストの再実行とは別に、重要な数値を別の実装で計算し直しました。スクリプトは `pipeline/research_validation/` にあり、結果は `data/quality/validation-9i-*.json` に保存しています。

| 対象 | 独立した計算 |
| --- | --- |
| 日別の便数 | 元のファイルを文字列のまま日付に分けて数え、研究用データ・公開データと照合（`temporal_counts.py`） |
| イベント研究の系列と統計 | 研究用の便ごとのデータを DuckDB で集計し、scipy の回帰と、定義どおりに書いた Newey-West で計算（`event_series.py`） |
| Systemic・Spillover | ネットワークを SQL で作り直し、scipy の最短経路で定義どおりに計算（`network_impact.py`） |
| 実験の順位相関 | 保存された値から、同順位を正しく扱って scipy で計算（`experiment_ties.py`） |
| 離島の到達可能性 | 素朴な幅優先探索で到達できる人口だけを計算（`island_access.py`） |

既存テストの成功と、独立した検証の成功は分けて記録しています（[research-validation.md](research-validation.md)）。

## F. 研究上の結論として維持できるもの

- 中東の観測便数は 2026年2月28日に大きく減った（11 か国で −70%、時間別では 2/28 の 06〜09 UTC から）。
- 中東の観測便数は、2月17〜18日ごろから勧告の前に減っていた（11 か国、Newey-West の t = −4.36）。原因は特定していない。
- Systemic と Spillover は上位の空港でほぼ同じ順位になる（上位 50 は一致、上位 157 で 0.99）。全空港では 0.76。
- 新石垣は世界のネットワークで中位（1,828 位、Spillover 0）だが、毎日の便では 49,822 人の唯一の経路。
- 2026年5月5〜7日の観測ゼロは収集停止。
- ティアで順位が大きく変わる（157 空港の中で、T1 のみ 0.22〜0.24）。
- 256 起点の近似は上位の空港の比較に使えない（上位 50 の一致 0.62〜0.64、誤差の中央値 約 45%）。

## G. 根拠が弱く、引き続き検証が必要なもの

- 低頻度路線への欠測が順位を動かしやすい：想定した欠測モデルと 10 試行の結果で、実際の欠測の分布は未知。
